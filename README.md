# Poster Size & Aspect Ratio Calculator

Free poster size calculator for checking image aspect ratio, maximum print size at 300 DPI, and compatibility with common poster formats.

## Free online poster size calculator

Use the live calculator:

**[Poster Size & Aspect Ratio Calculator](https://yougotprints.com/pages/poster-size-calculator)**

Upload an image and instantly check:

- Image dimensions in pixels
- Simplified aspect ratio
- Maximum print size at 300 DPI
- Poster size compatibility
- Exact fit, good fit, or crop needed

Images are processed locally in the browser and are not uploaded to a server.

## Supported poster sizes

The calculator checks image compatibility with:

- A4 — 21 × 29.7 cm
- A3 — 29.7 × 42 cm
- A2 — 42 × 59.4 cm
- A1 — 59.4 × 84.1 cm
- 30 × 40 cm
- 40 × 50 cm
- 50 × 70 cm
- 60 × 90 cm
- 18 × 24 in
- 24 × 36 in

## 300 DPI print size calculator

The tool uses image pixel dimensions to estimate maximum physical print size at 300 DPI.

`Image pixels ÷ 300 DPI = maximum print dimensions in inches`

The calculated result is also converted to centimetres.

## Chrome extension

This repository contains the source code for the Poster Size & Aspect Ratio Calculator browser extension.

The extension runs locally and requires:

- No account
- No backend
- No API
- No analytics
- No image uploads
- No Chrome permissions

## Install locally in Chrome

1. Download or clone this repository.
2. Open `chrome://extensions`.
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the repository folder.
